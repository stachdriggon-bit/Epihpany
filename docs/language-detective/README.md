# Language Detective — Content Design

This folder contains the authoring standards and case proposals for Language Detective.

## Design standard

- [Language Detective Case Design Standard](../LANGUAGE-DETECTIVE-CASE-DESIGN-STANDARD.md) — approved rules for task clarity, evidence, answer models, CEFR progression, modes, lore integrity, and case validation.

## Case proposals

Case proposals are drafts until reviewed. Saving a proposal in the repository does not make its events or new details part of The Resonance canon.

- [A1-001 — The Mark on the Traveler's Hand](./cases/A1-001-the-mark-on-the-travelers-hand.md) — first small pilot case based on the established meaning and limits of the restraint mark.

## Workflow

1. Review the case proposal against the design standard.
2. Confirm its evidence, task wording, answer model, and lore status.
3. Only after approval, translate the authored case into runtime data and assessment fixtures.
4. Add automated checks for the case's evidence boundaries, accepted answers, distractors, and mode invariants.
5. Build separate cases for each CEFR level; do not reuse a solved case as a harder-level case.
