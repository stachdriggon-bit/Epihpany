# EPIPHANY — Worldbuilding Documentation

This directory is the working reference for the fictional world of EPIPHANY. It is documentation only; it does not change the app runtime.

## Source-of-truth files

- [Master Content Bible](MASTER-CONTENT-BIBLE.md) — core principles and world rules.
- [Atlas](ATLAS.md) — geographic reference and map decisions.
- [Timeline](TIMELINE.md) — historical framework and chronology standards.
- [Civilizations](CIVILIZATIONS.md) — societies, cultures, states, and connections.
- [Characters](CHARACTERS.md) — character-canon template and continuity rules.
- [Mysteries and Evidence](MYSTERIES-AND-EVIDENCE.md) — mysteries, evidence, competing explanations.
- [Decision Log](DECISIONS-LOG.md) — accepted, provisional, and open decisions.

## Status vocabulary

- **Accepted:** approved as part of the current reference.
- **Provisional:** useful working proposal; may change with a recorded reason.
- **Open:** intentionally undecided.
- **In-world claim:** something a character, culture, document, or institution believes; not automatically objective truth.

## Working rules

1. Keep the ultimate origin of the world unresolved unless the project owner explicitly changes this principle.
2. Never silently turn a provisional idea into accepted canon.
3. When changing geography or chronology, check affected stories, characters, routes, cards, and other documents.
4. Separate evidence from interpretation and folklore.
5. Update this directory when a major worldbuilding decision is accepted.
6. Names and IDs are working identifiers; preserve IDs when names change where practical.

The current material records the initial worldbuilding conversation and is intentionally incomplete. It is not yet a final scaled atlas or a complete historical canon.
