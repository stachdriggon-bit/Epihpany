# Superseded: Provisional Sorcery Branch Model

**Status:** Superseded; historical reference only.  
**Do not use this document as current magic-system law.**

The former document at `docs/world/SORCERY-BRANCHES-AND-INDIVIDUAL-RESTRICTIONS.md` proposed a seven-branch taxonomy and a possible mapping between restriction categories and branches. That proposal has been retired because the project is now building the magic system from each sorcerer's basic ability, natural limits, individual restriction, and skill, rather than from fixed branches.

The old proposal is retained here only as a short record of what was tried. Its branch labels and proposed mapping are **not current rules**, and characters must not be forced into them.

Use [Foundational Sorcery Model](../MAGIC-FOUNDATIONS.md) as the current working reference. The original full document remains available in Git history if needed for historical comparison.

## Retired proposal

The old catalogue grouped operations under:
- Control and Transformation
- Creation and Replication
- Removal and Cancellation
- Amplification and Reduction
- Interference and Disruption
- Structural Relation Alteration
- Transfer and Redirection

These groupings are no longer an official taxonomy. Perception and Detection was explored separately, but it is not an official branch either.

## Why it was retired

The branch-first approach risked confusing a visible result with the underlying mechanism and limiting the imagination of future character abilities. Similar results may arise through different abilities, and similar basic abilities may develop differently depending on skill, restrictions, and discovery. Future organization, if useful, must follow actual examples rather than prescribe what an ability can do.
