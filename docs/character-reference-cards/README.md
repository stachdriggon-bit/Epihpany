# سجل بطاقات المعلومات المرجعية للشخصيات

هذا السجل هو المرجع المنهجي لإنشاء بطاقات معلومات موسعة لشخصيات EPIPHANY. هذه الوثائق **ليست بطاقات العرض داخل الموقع**؛ بل ملفات مرجعية تستخدم عند كتابة القصص والحوار والمهام وتصميم تجارب World ومراجعة اتساق الشخصيات.

## الغرض

- توحيد طريقة توثيق الشخصيات دون جعلها متشابهة في الشخصية أو القدرات.
- حفظ المعلومات المعتمدة منفصلة عن الفرضيات والأفكار قيد الاختبار.
- توفير مرجع مستمر لتجنب اختراع تفاصيل متناقضة أو إعادة فتح قرارات حُسمت سابقًا.
- جعل كل شخصية قابلة للتطوير دون تحويل اقتراح مؤقت إلى حقيقة سردية عن طريق الخطأ.

## الحالة المعرفية لكل معلومة

استخدم وسومًا واضحة عند الحاجة:

- **موثّق / معتمد:** معلومة اتُّفق عليها أو ثبتت في مرجع معتمد.
- **فرضية اختبارية:** تفسير أو تفصيل قيد الاختبار، وليس حقيقة نهائية.
- **مقترح:** فكرة جديدة لم تُراجع أو تعتمد بعد.
- **مفتوح:** قرار لم يُحسم.
- **غير معروف:** لا تتوفر معلومة موثوقة عنه؛ لا تملأ الفراغ بالتخمين.

لا ترفع حالة أي معلومة من فرضية أو مقترح إلى معتمد دون قرار صريح. وعند التعارض، لا تُخفِه؛ سجّل التعارض والمرجع الذي يحتاج إلى المراجعة.

## قالب بطاقة المعلومات المرجعية

ينبغي أن تتضمن البطاقة الأقسام المناسبة للشخصية، مع حذف ما لا ينطبق أو وسمه بأنه مفتوح بدل اختلاق إجابات.

1. **الهوية:** المعرّف الثابت، الأسماء باللغات المعتمدة، الألقاب، طبيعة الكائن، العمر أو المرحلة العمرية إن عُرف، وحالة السجل.
2. **ملخص الشخصية:** دورها السردي ووصف موجز لا يختزل الشخصية في قدرتها.
3. **المظهر والتصميم:** وصف موثوق أو مرجع بصري مع توضيح ما إذا كان معتمدًا أو تصوريًا.
4. **الشخصية والدوافع:** السمات، الأهداف المستقلة، المخاوف، التناقضات، وما قد يدفعها إلى اتخاذ قرارات صعبة.
5. **القدرات:** الاسم وحالة اعتماده، المجال الأساسي، آلية العمل المعروفة، النطاق، الشروط، ما يمكنها فعله وما لا يجوز افتراض أنها تفعله، والأمثلة.
6. **القيد الفردي:** الصياغة الحالية، حالة الاعتماد، طبيعة الحد الجوهري، محفزات ظهوره إن عُرفت، تدرج آثاره، ما لا يفعّله، وحدود التكيف. لا تُحدَّد فئة القيد قبل أن تدعمها طبيعة الحد وفق مبادئ القيود.
7. **التكاليف والآثار الجانبية:** تُذكر فقط إذا كانت موثقة؛ لا يُفترض وجود ثمن عام لكل قدرة.
8. **الخلفية والأسرار:** ما هو معلوم، وما يعرفه الجمهور داخل العالم، وما هو سر، مع تجنب الخلط بين معرفة المؤلف ومعرفة الشخصية.
9. **العلاقات:** طبيعة العلاقة، ما هو ثابت وما يزال احتمالًا، وأي تغيرات مهمة عبر الزمن.
10. **الصوت والحوار:** طريقة الكلام، العبارة المميزة وترجمتها الطبيعية إن اعتُمدتا، وما ينبغي تجنبه في الكتابة.
11. **الاستخدام السردي والعملي:** كيف يمكن توظيف الشخصية في القصص والمهام وWorld، وأمثلة متسقة وغير متسقة.
12. **اختبارات الاتساق:** الحالات المختبرة، الملاحظات الفعلية مقابل النتائج الافتراضية، والاستنتاجات التي تسمح بها الأدلة.
13. **القرارات المفتوحة وسجل التغييرات:** أسئلة محددة، القرارات التي تحتاج إلى موافقة، تاريخ المراجعة، والمراجع المرتبطة.

## قواعد الاتساق

- لا تخلط بين ندرة بطاقة الموقع وبين القوة أو الأهمية السردية.
- لا تخلط بين حدود القدرة الطبيعية والقيد الفردي، ولا بين القيد ونقص المهارة أو المعلومات.
- لا تستنتج وظائف جديدة من اسم القدرة أو مظهرها وحدهما.
- لا تجعل القيود اعتباطية، ولا تضف استثناءات فقط لحل مشهد.
- لا تعتبر سيناريو اختباريًا أو نتيجة افتراضية حدثًا فعليًا.
- احفظ المعرّف الثابت للشخصية عند تغيير الاسم أو اللقب.
- لا تنسخ تفاصيل شخصية إلى شخصية أخرى لمجرد التشابه؛ استخدم القالب كمنهج لا كقائمة صفات إلزامية.
- اربط كل بطاقة بسجلات العالم والقدرات ذات الصلة، وراجعها عند تغير القرارات المعتمدة.
